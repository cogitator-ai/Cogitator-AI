The package becomes the one source of the server protocol. `toAgentRunResponse()` builds the answer of an agent run for every adapter: output, thread, usage, tool calls (`{ id, name, arguments }`), `status` and `traceId`, plus `reasoning`, `pendingApprovals`, `structured`, `structuredError`, `truncated`, `blocked` and `iterationLimitReached` when they apply, never the system prompt, the history, trace spans or a paused run's checkpoint. `AgentStreamSession` builds the events of a streamed run: `start` and `finish` name the run's thread (a new one when the request sent none), parts close before a tool call, an answer given in one piece is sent as text, and `finish` carries the run's outcome. `parseRunRequest()` takes an `acceptContext` policy that refuses `context` keys clients may not set (none by default), `parseAddMessageRequest()` refuses roles the server does not accept (`system` by default), and `parseResumeRequest()` and `parseWorkflowRunRequest()` (which refuses `checkpoint: true`) join them. `refuseNonJsonBody()`, `parseJsonBody()` and `readJsonRequestBody()` refuse bodies that are not JSON with `415`, `withSwarm()` closes a swarm once its run ends, `swarmAgentNames()` lists every agent of a swarm, router and pipeline stages included, and `CONFORMANCE_CASES` with `ConformanceRuntime` and `checkConformance()` let an adapter's tests check it answers like every other.
