Cogitator Studio, a local debugger for agent projects: chat with every agent of the registry with streamed answers, reasoning, tool calls and threads; approve or reject tool calls that need it; read each run as a waterfall of model calls, tool calls and nested agents with tokens and cost; run workflows with live node statuses and rerun them from a node; fork a finished run from any step with a changed input, context or tool result and compare both branches. The project runs in a child process that reloads on save, and the history is kept in `.cogitator/studio/`.
