# Experimental API

APIs listed here carry the `experimental_` prefix, or are reached only through one. They work and are tested, but their shape may still change in a minor release, without a deprecation period. Each entry names the package, what it is and since when it is there. When an API becomes stable, it loses the prefix, moves out of this list and the old name stays as a deprecated alias for one minor release.

Keep this list complete: a pull request that adds an `experimental_` export adds it here.

## Plugins (since the plugins release of `@cogitator-ai/core`)

| API                                                                  | Package                                                             | What it is                                                                                                                                                                                                        |
| -------------------------------------------------------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CogitatorConfig.experimental_plugins`                               | `@cogitator-ai/types`, `@cogitator-ai/core`, `@cogitator-ai/config` | The plugins of a runtime: plugins in code, plugin folders, installed plugins, settings, MCP connector, secret store, isolation limits, watch                                                                      |
| `Cogitator.experimental_plugins`                                     | `@cogitator-ai/core`                                                | The runtime's plugin host                                                                                                                                                                                         |
| `experimental_PluginHost`                                            | `@cogitator-ai/core`                                                | Finds, enables, loads and reloads plugins by generation: `load`, `list`, `get`, `reload`, `setEnabled`, `snapshot`, `onChange`, `panelHtml`, `callPanel`, `diagnostics`, `dispose`, `configured`, `installedRoot` |
| `experimental_definePlugin`                                          | `@cogitator-ai/core`                                                | A plugin in code                                                                                                                                                                                                  |
| `experimental_validatePlugin`                                        | `@cogitator-ai/core`                                                | Checks a plugin folder as `claude plugin validate` does                                                                                                                                                           |
| `experimental_PluginInstaller`                                       | `@cogitator-ai/core`                                                | Installs, updates, enables, disables and removes plugins and marketplaces                                                                                                                                         |
| `experimental_keychainSecretStore`, `experimental_memorySecretStore` | `@cogitator-ai/core`                                                | Stores of plugin secrets: the operating system's credential store, or memory                                                                                                                                      |
| `experimental_mcpConnector`                                          | `@cogitator-ai/mcp`                                                 | Connects `.mcp.json` servers for plugins and subagents                                                                                                                                                            |
| `experimental_runPluginEvals`                                        | `@cogitator-ai/evals`                                               | Runs a plugin's eval suite in the format of `claude plugin eval`                                                                                                                                                  |
| `cogitator plugin ...`                                               | `@cogitator-ai/cli`                                                 | The plugin commands of the CLI                                                                                                                                                                                    |
| Studio Plugins page and panel bridge (`/api/plugins/*`)              | `@cogitator-ai/studio`                                              | Plugin status, reload, enable, and plugin panels                                                                                                                                                                  |

Types reached through these entry points, and as experimental as they are: `PluginsConfig`, `PluginDefinition`, `PluginContext`, `PluginManifest`, `PluginOptionSpec`, `PluginOptionValue`, `PluginDependency`, `PluginPermissionsSpec`, `PluginPanelSpec`, `PluginPanelContribution`, `PluginToolSpec`, `PluginSkillSpec`, `PluginInfo`, `PluginStatus`, `PluginOrigin`, `PluginContributions`, `PluginDiagnostic`, `PluginHostEvent`, `PluginSecretStore`, `PluginSettingsOptions`, `PluginIsolationConfig`, `PluginSource`, `PluginPin`, `InstalledPluginRecord`, `MarketplaceSource`, `MarketplaceManifest`, `MarketplacePluginEntry`, `KnownMarketplace` (`@cogitator-ai/types`), and `PluginHostOptions`, `PluginReloadResult`, `PluginSnapshot`, `PluginHookSet`, `PluginPanelEntry`, `PluginLayout`, `PluginValidation`, `PluginInstallerOptions`, `PluginInstallOptions`, `PluginInstallQuestion`, `PluginInstallResult`, `PluginUpdateResult` (`@cogitator-ai/core`), `PluginEvalOptions`, `PluginEvalResult` and the other `PluginEval*` types (`@cogitator-ai/evals`). The error codes `PLUGIN_*` and `SECRET_STORE_UNAVAILABLE` of `ErrorCode` belong to the same API.

Stable APIs the plugins release changed, not experimental: `ToolRegistry.register()` and `registerMany()` and `registerLLMBackend()` now return a disposer, `LLMPlugin`, `LLMPluginMetadata` and `LLMBackendFactory` moved to `@cogitator-ai/types` (still exported by core), and `DefinitionSource` has the value `plugin`.
