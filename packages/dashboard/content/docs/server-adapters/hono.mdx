title: Hono Adapter
description: Deploy Cogitator agents to any JavaScript runtime — Node.js, Bun, Deno, and Cloudflare Workers — using the lightweight Hono adapter.
---

The `@cogitator-ai/hono` package provides `cogitatorApp`, a factory function that returns a Hono app with all Cogitator routes pre-configured. Hono's multi-runtime design means you can deploy the same agent API to Node.js, Bun, Deno, or Cloudflare Workers without code changes.

## Installation

```bash
pnpm add @cogitator-ai/hono hono
```

## Basic Setup

```typescript
import { serve } from '@hono/node-server';
import { Cogitator, Agent, tool } from '@cogitator-ai/core';
import { cogitatorApp } from '@cogitator-ai/hono';
import { z } from 'zod';

const cogitator = new Cogitator({
  llm: {
    defaultModel: 'anthropic/claude-sonnet-4-5-20250929',
    providers: {
      anthropic: { apiKey: process.env.ANTHROPIC_API_KEY! },
    },
  },
});

const summarizer = new Agent({
  name: 'summarizer',
  description: 'Summarizes text in a few sentences',
  model: 'anthropic/claude-sonnet-4-5-20250929',
  instructions: 'You summarize text concisely. Keep it under 3 sentences.',
});

const app = cogitatorApp({
  cogitator,
  agents: { summarizer },
  enableSwagger: true,
});

serve({ fetch: app.fetch, port: 3000 });
```

## App Options

```typescript
interface CogitatorAppOptions {
  cogitator: Cogitator;
  agents?: Record<string, Agent>;
  workflows?: Record<string, Workflow>;
  swarms?: Record<string, SwarmConfig>;
  auth?: AuthFunction;
  enableSwagger?: boolean;
  swagger?: SwaggerConfig;
  enableWebSocket?: boolean;
  websocket?: WebSocketConfig; // { path?, maxPayloadSize?, upgradeWebSocket? }
  bodyLimit?: number; // max request body size in bytes, default 1 MiB
}
```

## Request Handling

- Bodies are validated before anything reaches the runtime: `input` must be a non-empty string, `context` an object, `threadId` a non-empty string, swarm `timeout` a positive number. Invalid bodies return `400 INVALID_INPUT`; bodies above `bodyLimit` return `413 PAYLOAD_TOO_LARGE`.
- Workflow `options` are limited to `maxConcurrency`, `maxIterations` (positive integers) and `checkpoint` (boolean); other options are dropped and wrongly typed ones return `400 INVALID_INPUT`. The body itself is optional.
- Thread messages accept the roles `user`, `assistant` and `system`; `metadata` is stored with the entry.
- `CogitatorError`s keep their HTTP status and code (for example `429 LLM_RATE_LIMITED`), `HTTPException`s keep their response, and other errors are logged and returned as `500 Internal server error`. A workflow that ends with an error is reported as a failure.
- Disconnecting clients abort the running agent, workflow or swarm.
- `GET /agents` exposes each agent's `description`, never its `instructions`; `GET /tools` returns parameters as JSON Schema.

## Multi-Runtime Deployment

The same `cogitatorApp` works across runtimes. Only the server entry point changes.

### Node.js

```typescript
import { serve } from '@hono/node-server';

const app = cogitatorApp({ cogitator, agents: { summarizer } });
serve({ fetch: app.fetch, port: 3000 });
```

### Bun

```typescript
const app = cogitatorApp({ cogitator, agents: { summarizer } });
export default { fetch: app.fetch, port: 3000 };
```

### Deno

```typescript
const app = cogitatorApp({ cogitator, agents: { summarizer } });
Deno.serve({ port: 3000 }, app.fetch);
```

### Cloudflare Workers

```typescript
const app = cogitatorApp({ cogitator, agents: { summarizer } });
export default { fetch: app.fetch };
```

## Authentication

The auth function receives Hono's `Context<HonoEnv>` and returns an `AuthContext`:

```typescript
const app = cogitatorApp({
  cogitator,
  agents: { summarizer },
  auth: async (c) => {
    const token = c.req.header('Authorization')?.replace('Bearer ', '');
    if (!token) throw new Error('No token');
    return { userId: 'user_123', roles: ['admin'] };
  },
});
```

The auth middleware applies to all routes via `app.use('*', ...)`.

## Mounting Under a Prefix

Since `cogitatorApp` returns a standard Hono app, you can mount it under any path in a parent app:

```typescript
import { Hono } from 'hono';

const root = new Hono();

root.get('/', (c) => c.text('Welcome'));
root.route(
  '/cogitator',
  cogitatorApp({
    cogitator,
    agents: { summarizer },
    enableSwagger: true,
  })
);

serve({ fetch: root.fetch, port: 3000 });
```

All Cogitator endpoints are now available under `/cogitator/agents/...`, `/cogitator/docs`, etc.

## Swagger & OpenAPI

When `enableSwagger` is `true`, the app registers `/openapi.json` and `/docs` routes. The spec is generated dynamically from the registered agents, workflows, and swarms using the shared `@cogitator-ai/server-shared` generator.

```typescript
const app = cogitatorApp({
  cogitator,
  agents: { summarizer },
  enableSwagger: true,
  swagger: {
    title: 'Summarization API',
    version: '1.0.0',
    servers: [{ url: 'https://api.example.com/cogitator', description: 'Production' }],
  },
});
```

## Streaming

The `HonoStreamWriter` uses Hono's native streaming support, which works across all target runtimes:

```typescript
const response = await fetch('http://localhost:3000/agents/summarizer/stream', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    input: 'Summarize the history of the internet in detail.',
  }),
});

const reader = response.body!.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

## WebSocket

WebSocket upgrades depend on the runtime, so pass your runtime's `upgradeWebSocket` helper. The endpoint runs behind the same middleware as the REST routes, including `auth`.

```typescript
import { Hono } from 'hono';
import { serve } from '@hono/node-server';
import { createNodeWebSocket } from '@hono/node-ws';

const root = new Hono();
const { upgradeWebSocket, injectWebSocket } = createNodeWebSocket({ app: root });

root.route(
  '/cogitator',
  cogitatorApp({
    cogitator,
    agents: { summarizer },
    enableWebSocket: true,
    websocket: { path: '/ws', upgradeWebSocket },
  })
);

injectWebSocket(serve({ fetch: root.fetch, port: 3000 }));
```

Use `upgradeWebSocket` from `hono/bun`, `hono/deno` or `hono/cloudflare-workers` on those runtimes. Without it the endpoint answers `501 UNIMPLEMENTED`.

Clients send `run` (`{ type: 'agent' | 'workflow' | 'swarm', name, input, context?, threadId? }`), `stop` and `ping`; the server answers with `event` (`token`, `tool-call`, `tool-result`, `complete`, `cancelled`), `error` and `pong`. Messages above `maxPayloadSize` close the socket with code `1009`, and closing the socket aborts its active run.

## Context Variables

Inside custom Hono routes, the Cogitator context is available via Hono's `c.get()`:

```typescript
import { Hono } from 'hono';
import type { HonoEnv } from '@cogitator-ai/hono';

const app = new Hono<HonoEnv>();

app.get('/custom', async (c) => {
  const ctx = c.get('cogitator');
  const auth = c.get('cogitatorAuth');
  const requestId = c.get('cogitatorRequestId');

  return c.json({ runtime: 'ready', requestId });
});
```
