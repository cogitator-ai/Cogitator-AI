title: Core API
description: Public exports of @cogitator-ai/core — runtime, agents, tools, LLM backends and the advanced subsystems — with their signatures.
---

Everything below is exported from `@cogitator-ai/core`. Types such as `AgentConfig`, `RunOptions` and `RunResult` live in [`@cogitator-ai/types`](/docs/api-reference/types) and are re-exported from core.

## Runtime

### `Cogitator`

```typescript
new Cogitator(config?: CogitatorConfig)
```

| Member                 | Signature                                                                                            | Purpose                                                                                  |
| ---------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `run`                  | `run(agent: Agent, options: RunOptions): Promise<RunResult>`                                         | Run an agent: LLM calls, tools, memory, guardrails, tracing                              |
| `resume`               | `resume(agent: Agent, target: RunCheckpoint \| string, options?: ResumeOptions): Promise<RunResult>` | Continue a run paused for [approvals](/docs/tools/approvals), by checkpoint or thread id |
| `tools`                | `readonly tools: ToolRegistry`                                                                       | Tools offered to every agent this instance runs                                          |
| `prompts`              | `get prompts(): PromptRegistry`                                                                      | [Versioned instructions and A/B tests](/docs/advanced/prompt-versions)                   |
| `getMemory`            | `getMemory(): Promise<MemoryAdapter \| undefined>`                                                   | The configured memory adapter, connected on first use                                    |
| `memory`               | `get memory(): MemoryAdapter \| undefined` / `set memory(adapter)`                                   | The connected adapter (`undefined` before first use), or set your own                    |
| `resolveModel`         | `resolveModel(agent: Agent): string`                                                                 | The agent's model, else `llm.defaultModel`; throws `CONFIGURATION_ERROR`                 |
| `route`                | `route(modelString: string, explicitProvider?: string): ModelRoute`                                  | Backend and provider-side model name for a model string                                  |
| `getLLMBackend`        | `getLLMBackend(modelString: string, explicitProvider?: string): LLMBackend`                          | The backend a model string runs on                                                       |
| `estimateCost`         | `estimateCost(params: { agent; input; options?: EstimateOptions; model? }): Promise<CostEstimate>`   | Cost estimate before running                                                             |
| `getCostSummary`       | `getCostSummary(): CostSummary \| undefined`                                                         | Tracked spend (with `costRouting`)                                                       |
| `getCostRouter`        | `getCostRouter(): CostAwareRouter \| undefined`                                                      | The cost router (with `costRouting`)                                                     |
| `getInsights`          | `getInsights(agentId: string): Promise<Insight[]>`                                                   | Reflection insights (with `reflection`)                                                  |
| `getReflectionSummary` | `getReflectionSummary(agentId: string): Promise<ReflectionSummary \| null>`                          | Reflection statistics                                                                    |
| `reflectionEngine`     | `get reflectionEngine(): ReflectionEngine \| undefined`                                              | The reflection engine                                                                    |
| `getGuardrails`        | `getGuardrails(): ConstitutionalAI \| undefined`                                                     | The guardrails instance                                                                  |
| `setConstitution`      | `setConstitution(constitution: Constitution): void`                                                  | Replace the guardrails constitution                                                      |
| `close`                | `close(): Promise<void>`                                                                             | Disconnect memory, stop sandboxes, release resources                                     |

See [Cogitator](/docs/core/cogitator) for the configuration.

### Run Checkpoints, Prompts, Threads

| Export                                                   | Signature                                                                              | Purpose                                                                                                            |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `InMemoryRunCheckpointStore`                             | `new InMemoryRunCheckpointStore()`                                                     | `RunCheckpointStore` in process memory                                                                             |
| `ThreadRunCheckpointStore`                               | `new ThreadRunCheckpointStore(memory: MemoryAdapter)`                                  | Keeps paused runs in thread metadata (the default with memory)                                                     |

| `promptKey`                                              | `promptKey(target: Agent \| string): string`                                           | Key instructions are versioned under (agent `id` if set, else `name`)                                              |
| `InMemoryInstructionVersionStore`, `InMemoryABTestStore` | `new …()`                                                                              | Default prompt stores                                                                                              |
| `threadOwner`                                            | `threadOwner(thread: Thread): string \| undefined`                                     | The `userId` a thread belongs to                                                                                   |
| `threadMetadata`                                         | `threadMetadata(owner: { agentId: string; userId?: string }): Record<string, unknown>` | Metadata for a new thread owned by a user                                                                          |
| `assertThreadAccess`                                     | `assertThreadAccess(memory, threadId, userId): Promise<Thread \| null>`                | Throws `THREAD_ACCESS_DENIED` for another user's thread                                                            |
| `ensureThreadAccess`                                     | `ensureThreadAccess(memory, threadId, owner: { agentId; userId? }): Promise<Thread>`   | Check access and create the thread when missing                                                                    |

## Agents and Skills

| Export                      | Signature                                                                         | Purpose                                                                                                             |
| --------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `Agent`                     | `new Agent(config: AgentConfig)`                                                  | An agent; defaults `temperature: 0.7`, `maxIterations: 10`                                                          |
| `agent.clone`               | `clone(overrides: Partial<AgentConfig>): Agent`                                   | Copy with changes                                                                                                   |
| `agent.serialize`           | `serialize(): AgentSnapshot`                                                      | JSON snapshot (tools by name)                                                                                       |
| `Agent.deserialize`         | `Agent.deserialize(snapshot: AgentSnapshot, options?: DeserializeOptions): Agent` | Restore from a snapshot (`toolRegistry`, `tools`, `overrides`)                                                      |
| `Agent.validateSnapshot`    | `Agent.validateSnapshot(snapshot: unknown): snapshot is AgentSnapshot`            | Check a parsed snapshot                                                                                             |
| `AgentDeserializationError` | `class extends Error`                                                             | Thrown by `deserialize` for unknown tools or bad snapshots                                                          |
| `defineSkill`               | `defineSkill(config: SkillConfig): Skill`                                         | Bundle tools and instructions (`name`, `version`, `description`, `tools`, `instructions?`, `env?`, `dependencies?`) |
| `validateSkill`             | `validateSkill(skill: Skill): SkillValidationResult`                              | Check a skill                                                                                                       |
| `mergeSkillsIntoAgent`      | `mergeSkillsIntoAgent(tools, instructions, skills): { tools; instructions }`      | What `new Agent({ skills })` does                                                                                   |

The instance getters `id`, `name`, `model`, `instructions`, `tools` and `config` read the configuration. See [Agents](/docs/core/agents).
