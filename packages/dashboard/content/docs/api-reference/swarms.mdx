## Swarm

```typescript
import { Cogitator, Agent } from '@cogitator-ai/core';
import { Swarm, swarm } from '@cogitator-ai/swarms';

const team = new Swarm(cog, {
  name: 'dev-team',
  strategy: 'hierarchical',
  supervisor: lead,
  workers: [developer, reviewer],
  hierarchical: { maxDelegationDepth: 2 },
});

const sameTeam = swarm('dev-team')
  .strategy('hierarchical')
  .supervisor(lead)
  .workers([developer, reviewer])
  .hierarchical({ maxDelegationDepth: 2 })
  .build(cog);

const result = await team.run({ input: 'Build a landing page' });
console.log(result.output, result.agentResults.get('developer')?.output);
```

### SwarmConfig

| Field                                                                                     | Type                                                                      | Used by                                                                                        |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `name`                                                                                    | `string`                                                                  | all                                                                                            |
| `strategy`                                                                                | `SwarmStrategy`                                                           | all                                                                                            |
| `supervisor`, `workers`                                                                   | `Agent`, `Agent[]`                                                        | `hierarchical` (supervisor required)                                                           |
| `agents`                                                                                  | `Agent[]`                                                                 | `round-robin`, `consensus`, `auction`, `debate`, `negotiation`                                 |
| `moderator`, `router`                                                                     | `Agent`                                                                   | `debate` moderator, specialist routing                                                         |
| `stages`                                                                                  | `PipelineStage[]`                                                         | pipeline stages (alternative to `pipeline.stages`; different stages in both throw)             |
| `agentMetadata`                                                                           | `Record<string, SwarmAgentMetadata>`                                      | role, expertise, priority, weight, `locked` per agent name                                     |
| `hierarchical`, `roundRobin`, `consensus`, `auction`, `pipeline`, `debate`, `negotiation` | strategy configs                                                          | the matching strategy; `consensus`, `auction`, `pipeline` and `debate` are required for theirs |
| `messaging`, `blackboard`                                                                 | `MessageBusConfig`, `BlackboardConfig`                                    | communication (`messaging.protocol` and `blackboard.locking` are deprecated, no effect)        |
| `agentTools`                                                                              | `SwarmAgentToolsConfig` (`{ messaging?: boolean; blackboard?: boolean }`) | built-in messaging / blackboard tools for every agent; local swarms only                       |
| `resources`                                                                               | `SwarmResourceConfig`                                                     | `maxConcurrency` (default 4), `tokenBudget`, `costLimit`, `timeout`, `perAgent`                |
| `errorHandling`                                                                           | `SwarmErrorConfig`                                                        | retry / skip / failover / abort on agent failure                                               |
| `distributed`                                                                             | `DistributedSwarmConfig`                                                  | run agents as Redis jobs                                                                       |
| `observability`                                                                           | `{ tracing?; messageLogging?; blackboardLogging? }`                       | logging; `tracing` logs each agent run's trace (spans)                                         |

### SwarmRunOptions and Results

```typescript
interface SwarmRunOptions {
  input: string;
  context?: Record<string, unknown>; // passed to all agents
  threadId?: string;
  userId?: string; // every agent run acts for this user
  timeout?: number;
  saveHistory?: boolean; // default: true
  onAgentStart?: (agentName: string) => void;
  onAgentComplete?: (agentName: string, result: RunResult) => void;
  onAgentError?: (agentName: string, error: Error) => void;
  onMessage?: (message: SwarmMessage) => void;
  onEvent?: (event: SwarmEvent) => void;
}

interface StrategyResult {
  output: unknown;
  structured?: unknown;
  agentResults: Map<string, RunResult>;
  votes?: Map<string, unknown>; // consensus
  bids?: Map<string, number>; // auction
  auctionWinner?: string;
  debateTranscript?: SwarmMessage[];
  pipelineOutputs?: Map<string, unknown>;
  negotiationResult?: NegotiationResult;
}
```

## Strategies

| `strategy`       | Class                  | Config (`SwarmConfig` field)                                                                                        | Needs                     |
| ---------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| `'hierarchical'` | `HierarchicalStrategy` | `hierarchical?: { maxDelegationDepth? (3), workerCommunication?, routeThrough?, visibility? }`                      | `supervisor`              |
| `'round-robin'`  | `RoundRobinStrategy`   | `roundRobin?: { sticky?, stickyKey?, rotation?: 'sequential' \| 'random' }`                                         | 1+ `agents`               |
| `'consensus'`    | `ConsensusStrategy`    | `consensus: { threshold, maxRounds, resolution: 'majority' \| 'unanimous' \| 'weighted', onNoConsensus, weights? }` | 2+ `agents`               |
| `'auction'`      | `AuctionStrategy`      | `auction: { bidding: 'capability-match' \| 'custom', bidFunction?, selection, minBid? }`                            | 1+ `agents`               |
| `'pipeline'`     | `PipelineStrategy`     | `pipeline: { stages: PipelineStage[], stageInput?, gates? }` (or top-level `stages`)                                | 1+ stages                 |
| `'debate'`       | `DebateStrategy`       | `debate: { rounds, maxTokensPerTurn?, format? }`                                                                    | 2+ `agents`, `rounds` ≥ 1 |
| `'negotiation'`  | `NegotiationStrategy`  | `negotiation?: Partial<NegotiationConfig>`                                                                          | 2+ `agents`               |

| Export                                                        | Signature                                                                                | Purpose                                     |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------- |
| `createStrategy`                                              | `createStrategy(coordinator: SwarmCoordinatorInterface, config: SwarmConfig): IStrategy` | The strategy for a config                   |
| `getDefaultStrategyConfig`                                    | `getDefaultStrategyConfig(strategy: SwarmStrategy)`                                      | Default config of a strategy                |
| `BaseStrategy`                                                | `abstract class BaseStrategy implements IStrategy` (`new (coordinator)`)                 | Base for your own strategy                  |
| `TurnManager`, `ConvergenceCalculator`, `ApprovalIntegration` | classes                                                                                  | Building blocks of the negotiation strategy |

Every strategy class takes `(coordinator, config)`. See [Strategies](/docs/swarms/strategies).

## Coordinators

| Export                        | Signature                                                                                                                                                           | Purpose                                                              |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| `SwarmCoordinator`            | `new SwarmCoordinator(cogitator: Cogitator, config: SwarmConfig)`                                                                                                   | In-process coordinator `Swarm` uses                                  |
| `DistributedSwarmCoordinator` | `new DistributedSwarmCoordinator(options: { config; distributed: DistributedSwarmConfig; resolveModel? })` — `initialize()`, `reset()`, `close()`                   | Runs agent turns as jobs on a Redis queue for `@cogitator-ai/worker` |
| `BaseSwarmCoordinator`        | abstract class                                                                                                                                                      | Shared coordinator logic                                             |
| `swarmJobQueueKey`            | `swarmJobQueueKey(keyPrefix?: string, queue?: string): string`                                                                                                      | Redis key of the agent job queue                                     |
| `ResourceTracker`             | `new ResourceTracker(config?: SwarmResourceConfig)` — `trackAgentRun`, `isWithinBudget`, `checkLimit`, `getUsage`, `getAgentUsage`, `getRemainingBudget`, `reset`   | Budgets                                                              |
| `CircuitBreaker`              | `new CircuitBreaker(config: { threshold; resetTimeout; successThreshold? })` — `canExecute`, `recordSuccess`, `recordFailure`, `getState`, `onStateChange`, `reset` | Per-agent failure breaker                                            |

`DistributedSwarmConfig`: `{ enabled, queue? ('swarm-agent-jobs'), timeout? (300000), redis?: { host?, port?, password?, keyPrefix?, db? }, retry?, cleanupAfter? (3600000), workerConcurrency? }`. `retry: { maxRetries? (3), backoff? ('exponential'), initialDelay? (1000), maxDelay? (30000) }` re-dispatches jobs that fail on a worker or time out (no retries without it). `cleanupAfter` is how long the swarm's Redis state is kept after `close()` (`0` deletes it at once). `workerConcurrency` is deprecated and has no effect; set `concurrency` on `DistributedSwarmWorker`. The job payload and result types are `SwarmAgentJobPayload`, `SwarmAgentJobResult` and `SerializedSwarmAgentConfig`. See [Distributed Swarms](/docs/swarms/distributed).

## Swarm Tools

Inside a swarm, the hierarchical supervisor gets the delegation tools, consensus voters the voting tools and negotiating agents the negotiation tools automatically; `agentTools` adds the messaging and blackboard tools to every agent. The factories build the same tools for custom strategies:

| Export                   | Signature                                                                | Tools                                                                                                                                                                     |
| ------------------------ | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createSwarmTools`       | `createSwarmTools(context: SwarmToolContext): Tool[]`                    | all of the tools below                                                                                                                                                    |
| `createStrategyTools`    | `createStrategyTools(strategy, context: SwarmToolContext): Tool[]`       | the set for a strategy                                                                                                                                                    |
| `createMessagingTools`   | `createMessagingTools(messageBus, currentAgent, swarmId?, options?)`     | `send_message`, `read_messages`, `broadcast_message`, `reply_to_message`                                                                                                  |
| `createBlackboardTools`  | `createBlackboardTools(blackboard, currentAgent)`                        | `read_blackboard`, `write_blackboard`, `append_blackboard`, `list_blackboard_sections`, `get_blackboard_history`                                                          |
| `createDelegationTools`  | `createDelegationTools(coordinator, blackboard, currentAgent)`           | `delegate_task`, `check_progress`, `request_revision`, `list_workers`                                                                                                     |
| `createVotingTools`      | `createVotingTools(blackboard, events, currentAgent, agentWeight?)`      | `cast_vote`, `get_votes`, `change_vote`, `get_consensus_status`                                                                                                           |
| `createNegotiationTools` | `createNegotiationTools(blackboard, events, currentAgent, agentWeight?)` | `make_offer`, `counter_offer`, `accept_offer`, `reject_offer`, `get_negotiation_status`, `get_current_offers`, `propose_coalition`, `join_coalition`, `declare_interests` |

`SwarmToolContext`: `{ coordinator, blackboard, messageBus, events, agentName, agentWeight?, swarmId? }`.

## Events

`SwarmEventType` covers the swarm lifecycle (`swarm:start`, `swarm:complete`, `swarm:error`, `swarm:paused`, `swarm:resumed`, `swarm:aborted`, `swarm:reset`), agents (`agent:start`, `agent:complete`, `agent:error`), messaging (`message:sent`, `message:received`, `blackboard:write`), each strategy (`consensus:*`, `auction:*`, `debate:*`, `pipeline:*`, `round-robin:assigned`, `negotiation:*`) and `assessor:complete`. A `SwarmEvent` is `{ type, timestamp, agentName?, data? }`; subscribe to `'*'` for all of them.
