description: Public exports of @cogitator-ai/memory with their signatures, from memory adapters, embeddings, hybrid search and context building to facts, memory items, sessions and knowledge graphs.

Every adapter method returns a `MemoryResult<T>` (`{ success: true, data } | { success: false, error }`). Check `result.success`, or use `unwrap()`:

```typescript
import { InMemoryAdapter, unwrap } from '@cogitator-ai/memory';

const memory = new InMemoryAdapter();
await memory.connect();

const thread = unwrap(await memory.createThread('agent-1', { topic: 'billing' }));
await memory.addEntry({
  threadId: thread.id,
  message: { role: 'user', content: 'Hello' },
  tokenCount: 2,
});
const entries = unwrap(await memory.getEntries({ threadId: thread.id, limit: 20 }));
```

| Export   | Signature                               | Purpose                                     |
| -------- | --------------------------------------- | ------------------------------------------- |
| `unwrap` | `unwrap<T>(result: MemoryResult<T>): T` | The `data`, or throws `Error(result.error)` |

`PostgresAdapter` keeps each fact as a memory item of its own slot `fact:<id>`: `updateFact` with new `content` supersedes the current item and keeps the old statement in the fact's history, `deleteFact` deletes the fact with its history, and a fact without evidence comes back without `evidence`. `MemoryItemAdapter` only stores: `findItems` returns items oldest recorded first and leaves out those let go (`expiredAt` not after now) unless `includeExpired`. See [Memory Items](#memory-items).

`defaultWeights` is `{ bm25: 0.4, vector: 0.6 }`. See [Hybrid Search](/docs/memory/hybrid-search).

## Context Building and Tokens

| Export                                      | Signature                                                                                                                                              | Purpose                                                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| `ContextBuilder`                            | `new ContextBuilder(config: ContextBuilderConfig, deps: ContextBuilderDeps)`                                                                           | Assemble history, facts, semantic and graph context within a token budget               |
| `builder.build`                             | `build(options: BuildContextOptions): Promise<BuiltContext>`                                                                                           | Messages plus `memoryContext`, `partitions`, `dropped`, `errors` and `warnings`         |
| `formatTurnContext`                         | `formatTurnContext(blocks: readonly string[]): string \| undefined`                                                                                    | The turn context text a context ends with, from texts of your own (none when all empty) |
| `withoutTurnContext`                        | `withoutTurnContext(text: string): string`                                                                                                             | The input of a message sent with a turn context, the `<memory_context>` part cut off    |
| `extendTurnContext`                         | `extendTurnContext(text: string, block: string): string`                                                                                               | `text` with `block` added to the turn context in front of it, or a new one there        |
| `markTurnEnds`                              | `markTurnEnds(history: Message[]): Message[]`                                                                                                          | Cache breakpoints at the end of a history and of the turn before its last one           |
| `ContextAssembler`                          | `new ContextAssembler(partitions?: Partial<Record<ContextPartition, ContextPartitionBudget>>)` - `assemble(budget, candidates)`, `budgetOf(partition)` | Share a token budget among partitions                                                   |
| `DEFAULT_PARTITIONS`                        | `Readonly<Record<ContextPartition, ContextPartitionBudget>>`                                                                                           | The partition budgets a config sets none for                                            |
| `fitInOrder`                                | `fitInOrder<T>(blocks: AssemblyBlock<T>[], budget: number): FitResult<T>`                                                                              | The default fit: blocks in order while they fit, skipping one that does not             |
| `countTokens`                               | `countTokens(text: string): number`                                                                                                                    | Token estimate                                                                          |
| `countMessageTokens`, `countMessagesTokens` | `(message: Message)`, `(messages: Message[])`                                                                                                          | Token estimates for messages, with tool calls and images                                |
| `countEntryTokens`, `countToolCallsTokens`  | `(entry: MemoryEntry)`, `(toolCalls: ToolCall[])`                                                                                                      | Recount a stored entry, estimate tool calls                                             |
| `truncateToTokens`                          | `truncateToTokens(text: string, maxTokens: number): string`                                                                                            | Cut text to a token budget                                                              |

`BuildContextOptions` is `{ threadId, agentId, userId?, systemPrompt?, currentInput?, maxTokens?, reserveTokens?, leafId?, pinned?, index?, brief? }`. `maxTokens` is this build's budget in place of the builder's, such as the context window of the model it is built for, and `reserveTokens` the room it keeps for the answer in place of the builder's. `leafId` is the entry the history ends at (the thread's active branch by default, none for `null`). `pinned` (a list), `index` and `brief` are texts of the partitions of the same names.

`BuiltContext.messages` is one system message (the system prompt, `pinned`, `index`), the compaction summary and the history with `cacheBreakpoint: true` on its last message and on the last message of the turn before (`markTurnEnds`), then a user message with `memoryContext` (the brief, facts, search results and graph context) when there is any. `partitions` holds the tokens each partition took, the input (`final`) included, and `tokenCount` the tokens of the context without it. The result's `dropped` (`DroppedContext`) lists the history entries, facts, search results and graph nodes left out, with their token count, and `blocks`, every left out block as a `DroppedBlock` with its `partition`, `reason` (`budget`, `duplicate`, `not-selected` or `oversized`), `tokens` and `sourceId`. With the `relevant` and `hybrid` strategies its entries include those the selection passed over, not only those the budget had no room for. See [Context Building](/docs/memory#context-building).

`ContextBuilderConfig` is `{ maxTokens?, strategy: 'recent' | 'relevant' | 'hybrid', reserveTokens?, includeSystemPrompt?, includeFacts?, includeSemanticContext?, includeGraphContext?, graphContextOptions?, partitions? }`, and `ContextBuilderDeps` is `{ memoryAdapter, factAdapter?, memoryItems?, embeddingAdapter?, embeddingService?, graphContextBuilder?, messageIndex? }`. With `memoryItems` (a `MemoryItems`) the facts partition holds the items the run's agent, user and thread see that hold now, one state per slot, in place of `factAdapter`'s facts.

`ContextAssembler.assemble<T>(budget, candidates: PartitionCandidates<T>[])` fills the partitions it is given, required ones first, then the others by their shares of what those leave, and `recent` last, and returns an `Assembly<T>`: `kept` blocks and `tokens` per partition, the `dropped` blocks and the tokens `used`. A `PartitionCandidates<T>` is `{ partition, blocks: AssemblyBlock<T>[], fit?, demand? }`, where `fit(blocks, budget)` returns a `FitResult<T>` (`{ kept, dropped, tokens? }`) for a partition whose blocks are not in order of importance, and `demand` is the tokens it needs when its blocks do not say. An `AssemblyBlock<T>` is `{ value, tokens, text?, sourceId? }`: blocks with `text` are left out as `duplicate` when a block a more lasting partition kept holds all of their text, word for word. A `share` outside 0 to 1, or shares of the partitions that are not required adding up to more than 1, throws. `BuildContextOptions`, `Assembly`, `AssemblyBlock`, `FitResult` and `PartitionCandidates` are exported as types.

## Core Facts, Sessions, Compaction

| Export                 | Signature                                                                                                                                                                                                                  | Purpose                                                                                                                                 |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `CoreFactsStore`       | `new CoreFactsStore(config: ({ path: string } \| { db }) & { scope?: MemoryItemScope })`: `initialize`, `set`, `get`, `getAll`, `delete`, `getHistory`, `formatForPrompt`, `close`                                         | Key-value facts about a user in SQLite, kept as memory items of the slots `core:<key>`, with history                                    |
| `SessionManager`       | `new SessionManager(adapter: MemoryAdapter, options?: { compaction?: CompactionService; indexRefreshInterval?: number })`: `getOrCreate`, `get`, `update`, `archive`, `list`, `delete`, `incrementMessageCount`, `compact` | Channel sessions per user and channel                                                                                                   |
| `CompactionService`    | `new CompactionService(config: { adapter: MemoryAdapter; summarize: SummarizeFn })`: `compact(sessionId, config)`, `chapterAtoms(window, config, options?)`, `applySummary(…)`                                             | Replace old entries with a summary                                                                                                      |
| `compactedHistory`     | `compactedHistory(path: readonly MemoryEntry[]): MemoryEntry[]`                                                                                                                                                            | The conversation of a branch read with `HISTORY_ENTRY_TYPES`: the latest compaction's summary, the entries it kept and everything after |
| `readCompactedHistory` | `readCompactedHistory(memory, { threadId, leafId?, includeToolCalls? }): Promise<MemoryResult<MemoryEntry[]>>`                                                                                                             | The same conversation, read in pages back only to where the latest compaction goes on from                                              |

`CompactionConfig` is `{ strategy, keepRecent, keepRecentTokens?, threshold?, messageThreshold?, chapterTokens?, chaptersPerArc?, arcsPerSaga?, summaryModel?, summaryPrompt? }`: a thread is compacted once it holds `threshold` tokens or `messageThreshold` entries (at least one is required). `strategy` is `'hierarchical' | 'summary' | 'sliding-window' | 'hybrid'`. The `hierarchical` strategy keeps the newest `keepRecentTokens` tokens of whole turns (else `keepRecent` entries), cuts what is new since the last compaction into chapters of `chapterTokens` (default 4000) and folds them into arcs (`chaptersPerArc`, default 4) and a saga (`arcsPerSaga`, default 4). Its `compaction` entry has `event.levels` (`CompactionLevels`) and the handoff as its message, and it is not written when it would lose an open control atom of the summary before it. `chapterAtoms(window, config, { own?, open? })` returns the checked atoms (`CompactionAtom[]`) of one window of entries, the structural ones taken from `own` and the summarizer told the `open` items it may close. See [Hierarchical Compaction](/docs/memory#hierarchical-compaction). `SummarizeFn` is `(messages: Message[], options?: SummarizeOptions) => Promise<string>`, where `SummarizeOptions` is `{ model?: string; prompt?: string }`, filled from `summaryModel` / `summaryPrompt` of the `CompactionConfig` passed to `compact()`.

## Types

Re-exported from `@cogitator-ai/types`:

```typescript
interface Thread {
  id: string;
  agentId: string;
  metadata: Record<string, unknown>; // metadata.userId: the owning user
  createdAt: Date;
  updatedAt: Date;
  activeLeafId?: string; // the entry the active branch ends at, absent with no entries
}

interface MemoryEntry {
  id: string;
  threadId: string;
  message: Message;
  toolCalls?: ToolCall[];
  toolResults?: ToolResult[];
  tokenCount: number;
  createdAt: Date;
  metadata?: Record<string, unknown>;
  type?: MemoryEntryType; // 'message' when absent
  parentId?: string | null; // the entry before it on its branch, null for the first
  seq?: number; // order the thread's entries were added in
  event?: Record<string, unknown>; // payload of an event entry
  formatVersion?: number; // MEMORY_ENTRY_FORMAT (2) for entries written now
}

type MemoryEntryType =
  | 'message'
  | 'tool_result'
  | 'model_change'
  | 'compaction'
  | 'approval'
  | 'interrupt'
  | 'label'
  | 'custom';

interface PathQueryOptions {
  threadId: string;
  leafId?: string; // default: the active leaf
  limit?: number; // the newest entries of the branch
  before?: string; // only entries before this one, to page back
  types?: readonly MemoryEntryType[] | 'all'; // default: CONVERSATION_ENTRY_TYPES
  includeToolCalls?: boolean;
}

interface Fact {
  id: string;
  agentId: string;
  content: string;
  category: string;
  confidence: number;
  source: 'user' | 'inferred' | 'system';
  createdAt: Date;
  updatedAt: Date;
  expiresAt?: Date;
  metadata?: Record<string, unknown>; // metadata.userId: only in that user's context
  evidence?: Evidence[]; // what it stands on, see Lineage
}

interface Embedding {
  id: string;
  sourceId: string;
  sourceType: 'message' | 'fact' | 'document';
  vector: number[];
  content: string;
  createdAt: Date;
  metadata?: Record<string, unknown>;
}

interface SearchResult {
  id: string;
  sourceId: string;
  sourceType: Embedding['sourceType'];
  content: string;
  score: number;
  vectorScore?: number;
  keywordScore?: number;
  metadata?: Record<string, unknown>;
}
```

`MemoryEntryType`, `PathQueryOptions`, `NewMemoryEntry`, `Evidence` and `EvidenceStatus` are re-exported here, `CompactionEvent`, the hierarchical compaction types (`CompactionAtom`, `CompactionAtomKind`, `CompactionNode`, `CompactionLevels`), `CONVERSATION_ENTRY_TYPES` (`['message', 'tool_result']`), `MEMORY_ENTRY_FORMAT` and the context types `ContextPartition`, `ContextPartitionBudget`, `DroppedReason` and `DroppedBlock` come from `@cogitator-ai/types`. `HISTORY_ENTRY_TYPES` (`['message', 'tool_result', 'compaction']`) is exported here. Also re-exported: the adapter configs, `MemoryQueryOptions`, `SemanticSearchOptions`, `SearchOptions`, `SearchFilter`, `HybridSearchConfig`, `ContextBuilderConfig`, `BuiltContext`, `DroppedContext`, `MemoryConfig`, the graph types (`GraphNode`, `GraphEdge`, `TraversalOptions`, `InferenceRule`, …) and the session types (`Session`, `SessionFilter`, `CompactionConfig`, `CompactionResult`; the interface is exported as `ISessionManager`).
