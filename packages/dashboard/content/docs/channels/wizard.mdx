## Overview

The `cogitator wizard` command provides an interactive TUI to configure a personal AI assistant. It generates a `cogitator.yml` config and `.env` file with all required secrets.

## Quick Start

```bash
npx @cogitator-ai/cli wizard
```

The wizard walks you through:

1. **LLM provider and model** — Google, OpenAI, Anthropic, or Ollama (local or cloud); models are fetched live
2. **Channels** — Telegram, Discord, Slack (bot tokens and owner user IDs)
3. **Capabilities** — web search, file system, GitHub, device tools, browser, scheduler, RAG, self-config, self-tools
4. **MCP servers** — any command line, quoted arguments supported
5. **Memory** — SQLite database path
6. **Personality** — custom system prompt for the assistant

Secrets are merged into `.env` without removing your other variables or comments. If `cogitator.yml` already exists, the wizard asks before overwriting it.

After setup, start the assistant:

```bash
cogitator up
```

## Editing an Existing Config

Re-run the wizard with `--edit` to modify an existing `cogitator.yml`:

```bash
cogitator wizard --edit
```

This loads the current config and pre-fills every prompt. Leaving a secret blank keeps the value already in `.env`; existing MCP servers and settings the wizard does not ask about (security, rate limits, stream tuning) are preserved.

## Generated Files

### cogitator.yml

```yaml title="cogitator.yml"
name: jarvis
personality: |
  You are Jarvis, a personal AI assistant.

llm:
  provider: google
  model: google/gemini-2.5-flash

channels:
  telegram:
    ownerIds: ["123456789"]

capabilities:
  webSearch: true
  scheduler: true

memory:
  adapter: sqlite
  path: ~/.cogitator/memory.db
  knowledgeGraph: true
```

### .env

```bash title=".env"
GOOGLE_API_KEY=your-api-key
TG_TOKEN=your-telegram-bot-token
```

## Programmatic Equivalent

Instead of the wizard, you can use `RuntimeBuilder` directly:

```typescript
import { RuntimeBuilder } from '@cogitator-ai/channels';

const builder = new RuntimeBuilder({
  name: 'jarvis',
  personality: 'You are Jarvis, a personal AI assistant.',
  llm: { provider: 'google', model: 'google/gemini-2.5-flash' },
  channels: { telegram: { ownerIds: ['123456789'] } },
  capabilities: { webSearch: true, scheduler: true },
  memory: { adapter: 'sqlite', path: '~/.cogitator/memory.db', knowledgeGraph: true },
}, process.env);

const runtime = await builder.build();
await runtime.gateway.start();
```

## Config Reference

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | `string` | required | Assistant name |
| `personality` | `string` | required | System prompt / personality |
| `llm.provider` | `google \| openai \| anthropic \| ollama` | required | LLM provider |
| `llm.model` | `string` | required | Model identifier (e.g. `google/gemini-2.5-flash`) |
| `channels` | `object` | `{}` | Channel configs (telegram, discord, slack) |
| `capabilities` | `object` | `{}` | Enabled capabilities |
| `memory.adapter` | `sqlite \| postgres` | `sqlite` | Memory storage backend |
| `memory.path` | `string` | `~/.cogitator/memory.db` | SQLite file |
| `memory.connectionString` | `string` | `DATABASE_URL` | Postgres connection (requires `pg`) |
| `memory.compaction.threshold` | `number` | — | Messages in a conversation before compaction |
| `memory.knowledgeGraph` | `boolean` | `true` | Enable knowledge graph |
| `memory.autoExtract` | `boolean` | `true` | Auto-extract entities from conversations |
| `capabilities.fileSystem.paths` | `string[]` | home dir | File tools are restricted to these paths |
| `capabilities.selfConfig` | `boolean` | `false` | Config/env tools — usable only by channel owners and the local terminal |
| `security.dmPolicy` | `open \| allowlist \| pairing \| disabled` | `open` | Who may DM the assistant |
| `stream.flushInterval` | `number` | `600` | Stream flush interval (ms) |
| `stream.minChunkSize` | `number` | `30` | Minimum chunk size before flushing |
| `rateLimit.maxPerMinute` | `number` | `30` | Per-user rate limit |
